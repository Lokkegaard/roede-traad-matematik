# Den røde tråd i matematik — Tarup Skole

Interaktivt overblik over matematikforløb, emner og faglige begreber fra 1. til 9. klasse, med tilknyttede [Skoledu](https://skoledu.dk)-forløb.

Baseret på dokumentet *"Den røde tråd i matematikundervisningen"*, Tarup Skole.

## Se siden live

https://lokkegaard.github.io/roede-traad-matematik/

## Om filen

`index.html` er en selvstændig, statisk HTML-fil (ingen build-trin) — al styling og logik ligger i selve filen. Åbn den direkte i en browser, eller besøg GitHub Pages-linket ovenfor.
